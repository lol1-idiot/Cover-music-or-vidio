Unduh hasil

Browser ini sepertinya tidak mendukung pemrosesan media secara langsung (butuh MediaRecorder & captureStream). Coba buka halaman ini di Chrome atau Edge versi terbaru, lebih baik di laptop/desktop.

Hasil akhirnya selalu file .webm. File dari URL harus tautan langsung ke berkas media dan servernya perlu mengizinkan akses lintas domain (CORS) supaya bisa ikut diproses, bukan cuma dilihat.
